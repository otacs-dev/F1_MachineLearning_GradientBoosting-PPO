# Race_List - Dados de Corridas

Calendário de corridas e informações de cada GP da temporada.

## Conteúdo

- **python_for_race_list.py** - Script para extrair dados de corridas
- **f1_cache_race_list/** - Cache de dados de corridas processados
- **Clima/** - Dados meteorológicos de cada circuito

Extrai calendário, informações de pista e dados climáticos das corridas.
