# Track_Results - Resultados Oficiais

Resultados das corridas por rodada da temporada 2025.

## Conteúdo

- **python_for_csvs_track_results.py** - Script para processar resultados
- **Round_X_[GP_Name]_2025_results.csv** - Resultados de cada Grande Prêmio

## Dados por Arquivo

Cada CSV contém:
- Posição final
- Piloto e equipe
- Pontos marcados
- Voltas completadas
- Status da corrida

Processa e organiza resultados oficiais das corridas.
